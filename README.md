# SHADOW ARENA

Standalone 3D browser action game. Open `index.html` through a web server or GitHub Pages.

## Controls
- Desktop: WASD move, mouse aim, left click fire, Space jump, R reload, 1/2 switch weapons.
- Android: left stick move, right-side buttons fire/jump/reload/switch, drag on right side to aim.

No paid APIs or assets are used.
